Financial Data Management Portal

Financial institutions file monthly transaction data with LIRS. Every row is checked before anything is kept.

Upload pipelineSimulation
Stored 0 · Rejected 0
How it works

A Go API hands each upload to a Rust worker over a Redis queue. Files sit in quarantine in S3-compatible storage until every row passes a versioned template. Clean files become permanent records; failed ones come back with an error report naming the row and column. Role-based access for institutions, admins and analysts, one-time passwords, a full audit log and FX-currency analytics.

Go · Rust · Redis · MySQL · S3/MinIO · React · TypeScript

    How it works

    Each QR code holds a signed token, not the person's details, so a photo can change or a card can be revoked without reprinting anything. Every scan, valid or not, is written to an audit log. Admins manage staff, photos and bulk CSV imports from a password-protected console, and it runs fully in-house with no paid services.
